# Login App

Proyecto académico de un formulario de inicio de sesión desarrollado con HTML, CSS y JavaScript.

## Funcionalidades

- Campo para ingresar el usuario.
- Campo para ingresar la contraseña.
- Validación de campos vacíos.
- Mensajes de validación para el usuario.

## Estrategia de ramas

Se utilizará Git Flow simplificado. La rama `main` contendrá la versión estable del proyecto y las ramas `feature/*` permitirán desarrollar funcionalidades de manera independiente. Los cambios se integrarán en `main` mediante Pull Requests revisados.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git y GitHub Actions
